# PC별 설치와 스킬 연계

공개 배포본의 사용법·보안 선택·라이선스·지원 경계는 저장소 루트 README.md와 docs/에 있습니다. hwpx/hwpx-windows-finalize를 sibling으로 유지합니다. 환경 설정은 Install-HangulSkills.ps1이 현재 사용자/CODEX_HOME에 생성하며 저장소에 포함하지 않습니다.

패키지의 hancom-setup은 캐시 위치에서 이 설치기를 찾습니다. 설정된 두 스킬은 설치 번들 경로를 환경에 보관합니다. 원본 해시 목록은 전송 무결성을 확인하며 게시자 신뢰·실제 COM·최종 지면을 인증하지 않습니다.

기본 설치는 Python/스킬 준비만 수행합니다. 공식 예제 모듈은 별도 AcceptGlobalFileAccess 선택을 요구합니다. 과거 승인 기록이나 PC 전용 선택 검증 증거를 가져오지 않습니다. 구체적인 한글 편집 결과는 해당 작업의 새 영수증으로 확인합니다.
