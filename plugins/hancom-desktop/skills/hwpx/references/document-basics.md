# 업무 문서 작성 기본 기준

계획서는 목적·대상·실행 방법·역할·일정·예산·안전을, 결과 보고서는 실제 결과·근거·집행·개선 조치를 읽을 수 있어야 한다. 문서 길이는 필요한 내용에 따라 정하며, 장문은 요지와 차례·본문·근거·부록을 목적에 맞게 구성한다. 짧은 요청이라고 설명과 근거를 잘라내지 않는다.

## 번호와 문단

- 번호는 의미상 상하 관계에 따라 쓴다. 대표 순서는 `1. → 가. → 1) → 가) → (1) → (가)`이며 설명을 이어 쓰는 문단까지 모두 번호화하지 않는다. 하위 번호는 상위 항목이 바뀌면 다시 시작한다.
- 실제 한글 NUMBER/BULLET 기능을 사용한다. 번호를 본문에 직접 입력하거나 선행 공백·탭을 반복하여 위치를 맞추지 않는다.
- 번호 시작점과 번호 뒤 본문 시작점은 다르다. 이번 스킬은 이어지는 줄을 본문 첫 글자에 맞춘다. 실제 PDF에서 두 줄 이상인 항목을 측정하고 눈으로 확인한다. `autoIndent=1`만으로 성공이라 하지 않는다.
- 공문 기안문의 공식 위치는 첫 단계 왼쪽 기본선, 다음 단계마다 2타 추가, 번호 뒤 1타이다. 내부 계획서에 적용해 온 스킬의 0/1/2칸 설정은 별도의 사용자 서식 관행이며 공식 0/2/4타와 혼동하지 않는다. 원본·기관 지정 규칙이 있으면 우선한다. 글자 크기별 공백 폭을 계산하고 임의의 고정 mm로 대체하지 않는다.
- 제목은 뒤 내용과 함께 두고, 짧은 실행 항목은 가능한 한 한 쪽에서 읽히게 한다. 제목·표·다음 본문 사이 간격을 모두 검토한다. 장식선은 필수가 아니며 글자에 닿으면 제거하거나 간격을 수정한다.

## 띄어쓰기와 표기

- 조사 붙임, 의존 명사 띄움 원칙을 지킨다. 예: `할 수 있다`, `확인한 후`, `제출 시`, `기관 간`, `이틀간`.
- 단위 명사는 띄어 쓰는 것이 원칙이며 아라비아 숫자와 결합한 표기는 붙임도 허용된다. 한 문서에서는 `200명`, `40권`, `1,500,000원` 등 선택한 방식을 통일한다. `150만 원`과 `1,500,000원`을 같은 뜻으로 쓰되 표에서는 한 방식을 유지한다.
- 날짜는 `2026. 12. 11.` 또는 `2026년 12월 11일` 등 일관된 형식을 쓴다. 문서의 작성일·파일 수정일을 제출 기한으로 옮기지 않는다. 기간과 확정·제안 상태를 구별한다.
- 짧은 제목·이름·수량 표기가 억지로 단어 중간에서 갈라지면 열 너비·표현을 조정한다. 글자 크기·장평·자간을 줄여 숨기지 않는다.

## 서식 선택과 완료 조건

지정서식 → 적합한 기존 원본의 사본 → 검증된 범용 서식 순으로 고른다. 원본을 재사용한다고 했으면 내용만 비우는 지원 편집을 우선한다. 새로 구성하면 재구성본이라고 밝히고 출처를 원본 양식처럼 표시하지 않는다.

검수는 본문과 표 전체에 적용한다. 실제 사용하는 번호 단계·그룹 재시작·선행 공백 없음·내어쓰기·줄/문단 간격·표 앞뒤 간격·쪽 경계·표 제목행 반복·합계·사실/가정 상태를 확인한다. 새 설계에서 의미상 필요한 단계가 빠지면 `check_document_basics.py --required-levels`로 거부한다. 이 도구는 맞춤법이나 의미상 위계, 시각 품질 전체를 자동 판정하지 않는다. 작성 에이전트의 문장 교정과 최종 한글 PDF 전체 검토가 별도로 필요하다.

초기 범용 서식 4종은 사용자 서식 지적에 따라 사용 중지했다. 운영계획서는 기본 규칙 적용 대체본만 검수 후 활성화했고, 결과·검토·장문 보고서 3종은 재검토 대기 상태다. 과거 ‘전체 쪽 확인’ 기록은 기본 작성 품질의 합격을 뜻하지 않는다. 재검증 없이 자동 선택하거나 새 출력에 쓰지 않는다. 사용 중지된 종류는 적합한 실제 원본을 찾거나 이 기준과 기존 v2 경로로 제대로 작성한다.

- [국립국어원, 한글 맞춤법 제43항 관련 답변](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=&pageIndex=1&qna_seq=336772): 단위 명사 띄어쓰기 원칙과 아라비아 숫자 결합 시 붙임 허용을 확인했다.
