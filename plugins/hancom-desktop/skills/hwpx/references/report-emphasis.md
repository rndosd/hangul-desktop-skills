# 보고서의 선택적 강조

제목·구조·독자의 판단에 필요한 정보가 눈에 들어오도록 강조를 설계한다. 큰 제목과 본문을 굵기·크기만으로 구분하여 지나치게 평평해지지 않게 한다. 지정 양식과 원본 서식이 있으면 우선하며 모든 문서에 같은 장식을 강제하지 않는다.

- 큰 제목은 옅은 배경 띠 또는 색 있는 구분선을, 하위 제목은 같은 계열의 굵은 글씨를 선택할 수 있다. 한 문서의 주조색은 일관되게 사용한다.
- 예산 소계·최종 합계는 옅은 음영과 굵은 글씨로 구분한다. 숫자 정렬·단위·산출 상태가 색 없이도 읽히게 한다.
- 제출 기한·핵심 금액 등 필요한 문구에만 밑줄·굵기·옅은 강조를 선택한다. 문단 전체나 미확정 수치를 무차별적으로 강조하지 않는다.
- 기존 글자 크기·장평·자간을 보존한다. 새 run 스타일을 만들 때 base id만으로 글자 크기가 보존된다고 가정하지 말고 원래 크기·굵기를 명시하고 저장 후 대조한다.
- 문단 테두리는 앞뒤 간격과 함께 실제 출력으로 확인한다. 배경 띠가 본문을 가리거나 표제 아래 선이 기관명에 닿으면 수정한다. 선 자체가 필수는 아니다.
- 번호는 실제 NUMBER/BULLET로 유지한다. 색 띠를 만들기 위해 번호를 본문 문자로 바꾸거나 임의 공백으로 밀지 않는다.

현재 운영계획서 대체 서식은 남색 #244E70, 옅은 청회색 #EAF1F7을 중심으로 만든 재구성본이다. 표제에 남색 윗선과 옅은 배경, 큰 항목에 배경·왼쪽 선, 표 머리글에 남색·흰 글씨, 합계에 음영을 사용한다. 이는 공식 기관 원본 복제본이나 의무 색상 규칙이 아니다.

실제 한글에서 빈 서식 2쪽 및 같은 규칙의 운영계획 4쪽을 저장·재열기·PDF 전체 검수했다. 실제 내용의 기한 밑줄과 합계 음영, 쪽 번호, 두 줄 이상 항목의 내어쓰기를 확인했다. 새로 채운 내용은 다시 검수한다.
