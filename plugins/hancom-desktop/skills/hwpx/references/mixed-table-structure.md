# 병합이 섞인 기존 표의 부분 구조 변경

짧은 요청에서 추가할 업무·삭제할 업무·같은 담당자 등 묶을 기준을 정하고, 원래 값과 변경할 값의 대응을 먼저 기록한다. 사용자가 내용 분류를 지정하지 않았다면 문맥에 맞는 안을 정한다. 아래 지원 범위는 도구의 검증 범위이며 모든 보고서에 강제하는 내용 형식이 아니다.

`scripts/mixed_table_structure_cli.py inspect SOURCE --table N`으로 원본 해시, 표 ID/전체 fingerprint, 격자 소유 셀을 읽는다. 한 표에 다른 병합이 있어도 해당 경계를 건드리지 않는 범위의 편집을 지원한다. 원래 고정크기/보호 가드를 유지하며 이 경로는 lock/noAdjust/sz.protect=0인2~100행/1~20열의 완전한 격자에만 적용한다. 표 전체를 단순표로 재작성하지 않는다.

요청 schema는 `hwpx.mixed-table-structure.v1`; 정확한 키는 schema/sourceSha256/table/tableId/tableSha256/operation/parameters/editableReason이다. 행/열과 range=[시작행,시작열,끝행,끝열]은1부터 센다. 사유는8자 이상, boolean을 좌표로 쓰지 않는다. `apply SOURCE NEW_OUTPUT --request REQUEST --dry-run`을 먼저 확인하고 새 사본에 적용한다. 완료 후의 해시로 다음 작업 binding을 다시 만든다.

- `clone_after`: parameters={row,cells,heightHwpunit}. 완전한 기존 데이터 행을 복제하고 그 바로 뒤에 넣는다. cells는 소유 셀→문단→run의 전체 문자열 지도다. 원래 가로 병합은 복제하지만 세로 병합을 가로지르는 행/삽입 경계는 거부한다. 신규 높이는1000~12000HWPUNIT 중 내용에 맞게 명시하며 기존 행 크기를 축소하지 않는다.
- `delete_row`: parameters={row}. 세로 병합과 교차하지 않는 지정 데이터 행만 삭제한다. 삭제할 값·유지할 값은 원본과 대조한다.
- `merge_duplicate_vertical`: parameters={range}. 인접한 두 단순 셀의 내용뿐 아니라 셀 크기/테두리/여백/문단/run서식이 일치할 때만 하나로 묶는다. 서로 다른 설명을 중복으로 취급하지 않는다. 문단 ID/줄 캐시/행 좌표만 비교에서 제외하며 위 셀의 완전한 내용을 보존한다.
- `merge_preserve_horizontal`: parameters={range}. 인접한 두 단순 데이터 셀을 합치며 오른쪽의 완전한 문단/run/ID/서식을 왼쪽 뒤에 옮겨 양쪽 설명을 보존한다. 글자만 합치거나 빈 값으로 지우지 않는다.
- `unmerge_vertical`: parameters={range,newCellTexts}. 정확히2행×1열이고 저장된 높이를 정수로 반씩 나눌 수 있는 셀을 분할한다. 위 셀은 유지하고 새 셀에는 원래 전체 문단/run서식을 복사한 뒤 명시한 새 문자열 지도를 적용한다. 다른 비율/임의 다축 분할은 별도 미지원이다.

대상 셀은 보호/제목 셀이 아닌1~5문단/문단당1~20run의 plain 텍스트만 허용한다. 원래 보고서의 `hp:t` 안에 있는 속성/자식/텍스트/tail 없는 literal `hp:fwSpace`는 보존한다. 일반 탭·필드·그림·OLE·임의 inline control은 이 텍스트 경로에서 거부한다. 원래 다른 셀/표의 병합과 컨트롤은 그대로 보존한다.

각 적용은 원본에서 만든 독립 전체-package 기대 트리와 대조하고 비대상 구역·공유 정의·그림 바이너리·기존 셀 크기/서식을 검사한다. 행 추가/삭제로 뒤쪽 rowAddr를 옮기는 것과 명시한 지역 geometry만 바뀐다. stale 해시/ID, 격자 구멍/겹침, 병합 경계 교차, 보호 셀, 불완전 문자열 지도는 출력 전에 거부한다.

독립 구조 검사는 실제 지면을 대신하지 않는다. 한글 열기→새 저장→저장본 재열기→PDF→반복 저장을 하고 원래/신규 셀 문구, 표 경계/잘림, 앞뒤 본문, 실제 목차를 확인한다. 실제 저장본에 같은 구조 기능을 다시 적용해 이후 편집도 확인한다. raw 구조 차이/전체 적용 서식/모든 공유 정의/PDF는 각각 기록하며 내부 FAIL을 PDF 동일성으로 덮지 않는다. 큰 새 행 때문에 표가 길어져 지면이 깨지면 기존 확장 표 흐름 경로의 적용 범위와 내용 의도를 별도로 확인한다.

실행 후보의 정상 종료 확인은 COM 창에서 얻은 pid/startTicks/exe가 현재 프로세스와 일치할 때만 최대10초 WaitForExit를 수행한다. 정상 Quit 또는 소유 근거가 없거나 제한 후 Hwp가 남으면 차단한다. 대기 중 임의 종료/승인창 자동조작/설정 변경은 하지 않는다. 지연 원인과 모든 PC 호환성은 이 대기만으로 증명되지 않는다.
