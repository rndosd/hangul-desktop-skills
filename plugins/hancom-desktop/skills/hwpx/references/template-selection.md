# 기존 서식 선택

## 선택 순서

1. 사용자가 형식으로 지정한 서식 또는 제출기관 지정서식을 우선한다. 내용 참고용 예시와 형식 지정은 구분한다.
2. 없는 경우 `assets/document-templates/catalog.json`에서 목적에 맞는 실제 원본·견본을 고른다. 기본 목적은 계획서(plan), 보고서(report), 안내/신청서(notice), 회의문서(meeting) 네 갈래다.
3. 필요하면 추가 원본을 확보한다. 적합한 것이 없다는 이유로 빈 문서 생성·초기 합성 서식으로 전환하지 않는다.

```powershell
& $pythonExe -X utf8 "$taskSkillDir/scripts/select_document_template.py" --list
& $pythonExe -X utf8 "$taskSkillDir/scripts/select_document_template.py" --kind plan --output "업무폴더/새 계획서.hwpx"
& $pythonExe -X utf8 "$taskSkillDir/scripts/select_document_template.py" --source "사용자서식.hwpx" --output "업무폴더/새 사본.hwpx"
```

목록의 기본 후보는 완성 문서가 아니라 원본 기반 작성의 출발점이다. 보관 파일·해시·원래 기관과 용도·실제 확인 범위·보완점을 함께 확인한다. 과거 합성 빈 서식은 선택 목록에서 제외했다. 세부 원본은 `--all` 또는 `--id`로 고른다.

## 용도와 관련 서식

| 기본 용도 | 기본 후보 | 필요할 때 추가 |
|---|---|---|
| 계획서 | 경남교육청 행복마을학교 운영계획 원본 | 예산 산출표·운영 시간표·다른 추진계획 원본 |
| 보고서 | 행안부 업무보고 원본 | 결과보고·사진 기록·정산·표지·차례 |
| 안내/신청서 | 경남 공개 한 장형 안내·신청 원본 | 여러 쪽 안내·시간표·동의·취합표 |
| 회의문서 | 경남교육청 지원도구의 회의록 표 | 학생대표 안건제안·서명부 |

독립 정산·품의·결의·검수는 보고서에 강제 합치지 않는다. 한 장형 동의는 개인정보와 사진 공개 체크 구분을 보완하고 실제 필요 항목만 수집하도록 작성한다. 학교운영위원회 학생대표 안건제안서를 일반 회의 안건지와 혼동하지 않는다. 일반 안건지의 검토의견·의결사항 완성형 원본은 추가 확보 대상이다.

`.hwp` 원본은 같은 확장자의 사본으로 복사한다. HWPX 편집 API가 필요하면 [구형 HWP 변환](workflows-hwp-conversion-windows.md)으로 HWPX 사본을 만든 뒤 사용한다. 확장자만 바꾸지 않는다.

## 변형과 검수

[원본 기반 작성](source-template-reuse.md)에 따라 제목·본문·표·강조·여백·쪽 흐름을 먼저 확인하고 내용에 맞게 변형한다. 원본의 모든 크기와 항목 수를 고정하지 않는다. 원본을 보존한 별도 사본에 지원되는 편집을 적용하고 실제 한글 출력에서 내용·수치·가독성·배치를 확인한다. 원본 검수는 새로 채운 결과의 검수를 대신하지 않는다.

## 긴 문서

보고서 안에서 필요한 표지·요약·차례·장별 본문·결론·참고·부록을 선택한다. 분량은 내용에 따라 늘리며 짧은 요청을 한두 쪽으로 제한하지 않는다. 현재 행안부 원본은 표지·차례·장별 본문을 제공하지만 참고문헌·부록까지 완성된 범용 틀은 아니다. 필요 구역은 적합한 기존 원본을 추가 확보해 같은 기본 디자인으로 맞춘다. 자동 차례 여부와 최종 쪽 번호를 실제 문서에서 확인한다.
