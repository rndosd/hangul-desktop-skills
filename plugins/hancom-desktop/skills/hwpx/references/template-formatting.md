# 기존 서식 변형의 가독성과 배치

선택한 원본의 제목·서체·번호·표·강조를 출발점으로 삼되 사용자·제출기관의 고정 조건을 우선한다. 원본 크기와 쪽수에 내용을 억지로 맞추지 않는다. [업무 문서 기준](document-basics.md)과 [번호 체계](template-numbering.md)를 필요한 범위에서 적용한다.

## 제목·표·강조

- 본문 내용표를 추가·변형할 때 큰 번호 제목은 표 밖의 독립 문단, 표는 별도 문단에 둔다. 번호 제목을 표와 같은 문단·셀에 붙이지 않는다. 원본 장식 표제가 표·도형으로 만들어졌으면 그 구성은 재사용할 수 있다.
- 제목과 표 윗선, 표 아랫선과 다음 큰 제목 사이에 구분되는 간격을 확보한다. 기존 양식의 간격을 우선하고 고립 제목·붙은 테두리를 조정한다. 과도한 빈 문단으로 간격을 흉내 내지 않는다.
- 핵심 제목·판단·기한·합계의 색·음영·굵기·밑줄은 [선택적 강조](report-emphasis.md)를 따른다. 같은 역할에는 같은 강조를 쓰고 실제 글자 크기·번호·내어쓰기와 선·글자 사이 간격을 검수한다.

## 줄바꿈·빈 공간

- 짧은 이름·역할·학년·시기 표기가 단어 중간에서 나뉘면 문구를 그대로 둔 채 해당 열의 유효 폭을 먼저 늘리고 다른 열을 재배분한다. 긴 설명의 자연스러운 줄바꿈과 구분한다. 전체 표 폭 확대는 본문 폭과 고정 조건 안에서만 선택한다. 지원 도구는 [어절·열 너비](word-flow.md)를 따른다.
- 내용이 줄어든 표의 위아래 빈 공간은 열 너비와 별도로 다룬다. 빈 문단, 문단 앞뒤 간격, 셀 위아래 안 여백, 명목 행 높이를 각각 확인하고 지원되는 편집으로 필요한 항목을 줄인다. 저장본을 다시 읽어 빈 문단 수·내용·서식 보존을 대조하고 실제 한글 PDF의 행 높이가 줄었는지 확인한다. 행 높이 수치 변경만으로 완료하지 않는다.
- 긴 표는 반복 제목·셀/행 쪽 나눔·표 뒤 본문·남는 공간을 확인한다. 분량은 필요한 설명으로 정하고 큰 여백·빈 행으로 늘리지 않는다.

## 설명이 많은 표의 밀도

기존 양식 보존은 변형하지 않기로 한 구조와 필수 표기를 지킨다는 뜻이다. 표의 단계명·행·열은 요청에 맞게 변형하며 빽빽한 원본의 행간·여백을 그대로 답습하지 않는다. 작성 전에 적용 중인 행간·문단 간격·유효 셀 안 여백을 확인한다.

핵심 행동·판단 기준은 짧게 쓰고 반복 설명·세부 운영 절차는 관련 문단·행·붙임이나 별도 운영 메모로 나눈다. 필수 정보는 문서 전체의 대응 위치로 확인하며 셀마다 모두 반복하지 않는다.

긴 텍스트에 100% 안팎의 행간과 좁은 안 여백이 있으면 재검토한다. 내용 축약, 셀 안 여백, 행간·문단 간격을 지원 범위에서 조정한다. 행간 135~150%·좌우 안 여백 2~3mm는 비교 후보이며 고정값·자동 합격선이 아니다. 글자 축소·자간 압축으로 빽빽하게 맞추지 않으며 필요하면 쪽 수 증가를 허용한다.

## 실제 출력 확인

내용 변경의 영향을 받은 주변 요소까지 정렬·간격·밀림과 배치 균형을 확인한다. 원본 크기를 유지하는 것보다 내용에 맞는 자연스러운 배치를 택하되 고정 조건은 지킨다. 평상시 읽는 크기의 글자 밀도, 항목 구분, 글과 셀 테두리 사이 여유도 검토한다. 구조/열기 성공이나 잘림 없음만으로 완료하지 않으며 빽빽한 결과는 수정·재검수한다. 글자 수·간격 수치는 보조 근거로 쓰고 최종 밀도 평가는 실제 쪽 검토로 기록한다.

구조·저장값 검사와 실제 시각 검수는 구분한다. 모든 변경 쪽과 주변을 확인하고, 인쇄/제출·조판 완료는 형제 finalize의 [공통 완료 기준](../../hwpx-windows-finalize/references/acceptance-policy.md#공통-완료-기준)에 따라 PDF 전체 쪽을 검수한다.
