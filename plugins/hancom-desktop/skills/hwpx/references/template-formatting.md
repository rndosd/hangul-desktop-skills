# 기존 서식 변형의 가독성과 배치

선택한 원본의 제목·서체·번호·표·강조를 출발점으로 사용한다. 원본 크기와 쪽수에 내용을 억지로 맞추지 않는다. [업무 문서 기준](document-basics.md), [번호 체계](template-numbering.md), [선택적 강조](report-emphasis.md)를 필요한 범위에서 적용한다.

- 제목과 표는 별도 문단에 두고 위·아래 간격을 실제 출력에서 확인한다. 고립 제목·표 테두리와 붙은 제목·과도한 빈 문단을 조정한다.
- 짧은 항목명·이름·학년·역할은 불필요하게 단어 중간에서 나뉘지 않도록 열의 유효 폭을 조정한다. 긴 설명은 문단·행·붙임으로 나눈다.
- 셀 안 여백, 행간, 문단 간격, 명목 행 높이를 각각 확인한다. 설명이 많은 표는 기존 값도 재검토한다. 글자 축소·자간 압축으로 빽빽하게 맞추지 않는다.
- 핵심 제목·판단·기한·합계에는 원본의 색·음영·굵기·밑줄을 필요한 만큼 활용한다. 같은 역할에는 같은 강조를 쓴다.
- 긴 표는 반복 제목·셀/행 쪽 나눔·표 뒤 본문·남는 공간을 확인한다. 분량은 필요한 설명으로 정하고 큰 여백·빈 행으로 늘리지 않는다.
- 구조·저장값 검사와 실제 시각 검수는 구분한다. 실제 한글 PDF의 모든 변경 쪽과 영향을 받은 주변을 확인하며 전면 재작성은 전체 쪽을 검수한다.
