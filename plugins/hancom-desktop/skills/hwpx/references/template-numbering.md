# 원본의 번호 체계와 들여쓰기

선택한 원본의 제목·하위 항목·본문 관계를 먼저 읽고 같은 체계를 이어 쓴다. 이미 원본에 있는 번호·도형 제목을 빈 문서의 신규 번호로 재구성하지 않는다.

독립된 병렬 항목과 앞 항목을 설명하는 문단을 구분한다. 필요한 단계만 사용하고, 짧은 안내문에 다단계 번호를 강제하지 않는다. 추가 항목에는 가능한 기존 NUMBER/BULLET 정의와 문단 스타일을 재사용한다. 새 번호 정의가 필요하면 지원되는 번호 편집으로 설정하며 공백 문자열로 들여쓰기를 흉내 내지 않는다.

같은 역할의 항목은 번호 단계·글자 크기·들여쓰기·문단 앞뒤 간격을 맞춘다. 첫 줄의 본문 시작과 줄바꿈 뒤 본문 시작이 자연스럽게 정렬되는지 [내어쓰기 검수](hanging-indent-verification.md)와 실제 한글 PDF로 확인한다. 번호 재시작·그룹 연속·중복·누락과 최종 차례·쪽 번호도 내용에 필요한 범위에서 확인한다.

숫자·통계·수량·금액은 제공한 값과 단위를 보존하고 합계를 독립 대조한다. 자료에 없는 범주·인원·잔액 원인을 추정해 채우지 않는다. 미정은 사용하는 위치에 표시하고, 제안은 확정 사항과 구별한다.
