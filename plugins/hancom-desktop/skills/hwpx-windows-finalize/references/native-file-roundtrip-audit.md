# 저장 전후 한글 파일의 별도 읽기 검사

PDF 동일성과 HWPX 보존은 각각 판정한다. 원본·작성본·native 저장본·반복 저장본·같은 기능으로 다시 편집한 파일을 유지한다. 파일 hash 차이만으로 손상/무손상을 단정하지 않는다.

`scripts/audit_native_file_roundtrip.py source.hwpx saved.hwpx --output new-audit.json`은 읽기 전용이다. 같은 폴더의 compare_active_semantics.py와 compare_package_definitions.py가 필요하다. 파일/ZIP 구성/원시 XML(속성·본문·tail·순서)/활성 구조/전체 정의를 각각 기록한다. PDF는 별도 검사하며 이 도구는 COM이나 시각·재편집 완료를 부여하지 않는다. 기존 출력 또는 입력 경로로 쓰기를 거부한다. exit0은 전체 파일 동일 및 활성/전체 정의 PASS, exit3은 차이를 보고했다는 뜻이다. DIFFERENT를 자동 손상으로 해석하지 않는다.

자간·장평 재편집의 미사용 정의 삭제와 긴 표 직접 높이 갱신은 PDF가 같아도 검출돼야 한다. 긴 표 높이가 첫 물리 조각에 가까운 사례가 있으나 공식 HWPX 의미/임의 문서 보존이 확정된 것은 아니다. 해당 높이·캐시·수정일을 통째로 무시하거나 출력이 같다는 이유로 PASS 처리하지 않는다. 셀 크기·병합·행/열 구조·테두리·개체/바이너리·번호·모든 정의와 실제 같은 기능 재편집을 별도로 확인한다.

HWP053의11조건/22쌍에서5쌍 내부 차이와17쌍 활성/전체 정의 보존, PDF22쌍 동일을 분리했다. 6CLI가드 확인. 원인 분리 회차이며 편집기 수정·배포 합격을 뜻하지 않는다.
