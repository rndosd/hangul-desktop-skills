# 조립 고정 시험 세트

조립·등록을 고친 뒤 이 세트만 돌려 통과하면 멈춘다. 문제를 하나 볼 때마다 규칙을 더하지 않고, 이 세트에서 실패한 것만 고친다.

## 1. 짧은 요청 10개 (에이전트 시험)

설치본을 쓰는 다른 모델(Sonnet)에게 아래 문장만 준다. 각 요청 끝에 "질문 없이 알아서 만들고, 이 폴더에 PDF도 같이 저장해 줘."를 붙인다. 기능 이름은 알려 주지 않는다.

| 요청 | 기대 양식 |
|---|---|
| 우리 학교 가을 운동회 운영계획서 한글 문서로 만들어줘. | `plan-school` |
| 우리 반 2학기 학급 텃밭 가꾸기 운영계획서 한글 문서로 만들어줘. | `plan-school` |
| 다문화 학생 한국어 학습 지원 프로그램 계획서 한글 문서로 만들어줘. 교육지원청에 낼 거야. | `plan-education` |
| 우리 학교 디지털 교육 3개년 종합 추진계획 한글 문서로 만들어줘. | `plan-project` |
| 2027학년도 신입생 반편성 배치고사 시행계획 한글 문서로 만들어줘. | `plan-official` |
| 학교폭력 예방 교육 주간 사업계획서를 한글 문서로 5~6쪽 정도로 만들어줘. | `plan-official` 또는 `plan-education` |
| 2학기 독서교육 운영 결과 보고서를 한글 문서로 만들어줘. | `report-brief` 또는 `plan-official` |
| 1학기 학교폭력 실태조사 결과를 한두 쪽으로 정리해서 한글 문서로 만들어줘. | `report-brief` |
| 신입생 학부모 설명회 개최 계획을 한글 문서로 만들어줘. | `event-plan` |
| 교육청 담당자 학교 방문 일정 안내를 한글 문서로 만들어줘. | `event-plan` |

합격: 기대 양식 선택, `PASS_NATIVE`, `pageLayout` 경고 없음(또는 고쳐서 없앰), 개요가 장·○만이 아님(소제목·하위 항목·표 중 둘 이상), 쪽 이미지에 깨진 곳 없음. 결과는 쪽 이미지를 한 장에 모아 사람이 본다.

## 2. 등록 문서 6개 (도구 시험)

`run_registrations.py 원본폴더 작업폴더`가 아래를 차례로 `register`하고 표 하나로 요약한다. 원본은 저장소에 넣지 않는다(출처는 아래). 합격: 모두 `REGISTERED`, `problems` 없음.

| 파일 이름 | 출처 | `--start` | 보는 것 |
|---|---|---|---|
| `gne-space.hwpx` | 경남교육청 행복마을학교 「공유 공간 운영 계획」 | | 일반 계획서, 단계표·사진표 |
| `gg-exchange.hwpx` | 경기도교육청 「시·도간 교류 추진 계획」(23쪽) | | 섞인 표의 반복 표 부품(`unitRow`), 블록 다수 |
| `labor-survey.hwpx` | 정책브리핑 고용노동부 노동교육 실태조사 보도자료 | 실태조사 주요 결과 | 장 없는 붙임, 라벨 표지, 결과 표 |
| `youth-forum.hwpx` | 정책브리핑 성평등가족부 청소년 디지털 안전 포럼 보도자료 | 포럼 개최 계획 | 본문에 같은 문구, 상자 안 표(블록) |
| `export-visit.hwpx` | 정책브리핑 산업통상부 K-수출스타 보도자료 | 현장방문 개요 | 프로그램 표 |
| `csat-plan.hwpx` | 교육부 「2027학년도 대학수학능력시험 시행기본계획」 | | 긴 공문서형 계획 |

기본 양식 6종의 재현은 `../check_assembly_reproduction.py`가 따로 본다.
