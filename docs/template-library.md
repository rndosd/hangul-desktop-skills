# 기본형과 우리 학교 양식 등록

기본 제공은 완성형 계획서 3종입니다. 원본 서식 13개·서식 합본·작은 블록을 찾아 조합하는 방식은 현재 기본 사용법에서 제외했습니다. 과거 출처·검증 자료는 이력 확인용으로 보존합니다.

| 기본형 | 사용할 상황 | 미리보기 |
|---|---|---|
| 학교 교육활동형 (`plan-school`) | 학교 행사·교육활동 운영계획 | [PDF](../plugins/hancom-desktop/skills/hwpx/assets/document-templates/full-plans/plan-school/template.pdf) |
| 교육사업 추진형 (`plan-education`) | 교육사업·프로그램 추진계획 | [PDF](../plugins/hancom-desktop/skills/hwpx/assets/document-templates/full-plans/plan-education/template.pdf) |
| 종합사업 추진형 (`plan-project`) | 여러 세부 과제가 있는 종합계획 | [PDF](../plugins/hancom-desktop/skills/hwpx/assets/document-templates/full-plans/plan-project/template.pdf) |

기본형에는 디자인·입력 위치·반복 문단과 표의 연결이 준비돼 있습니다. 예전 기관명·날짜를 바꾸는 일을 매번 되풀이하지 않고 새 내용을 채웁니다. 내용에 따라 분량과 구성을 조정하며, 실제 출력 검수는 작성할 때마다 필요합니다.

## 기본형으로 시작하기

> 기본 제공 계획서 3종 중 이번 내용에 적합한 하나로 독서 주간 운영계획서를 만들어줘. 아래 메모를 반영하고 미정인 날짜·담당자·예산은 미정으로 표시해줘. 원본은 보존하고 HWPX와 실제 출력 확인 결과를 줘.

## 우리 학교 양식을 기본형으로 준비하기

학교에서 쓰는 계획서 HWPX를 제공하고 다음처럼 요청합니다. 처음 구조를 분석하고 입력을 연결하는 작업은 성능이 좋은 모델을 권합니다. 특정 모델의 성공을 보장하는 뜻은 아닙니다.

> 첨부한 우리 학교 계획서를 반복해서 사용할 개인 기본 양식으로 등록해줘. 원본과 디자인은 보존하고, 옛 행사명·날짜·담당자·예산 등을 새 내용으로 채울 수 있도록 준비해줘. 개인 업무 폴더에 양식·입력 연결·목록을 두고 앞으로 한글 스킬에서 사용할 수 있게 연결해줘. 가상 내용으로 채워 실제 한글 출력까지 시험해줘. 기본 제공 3종과 다른 사용자 양식은 변경하지 마.

등록은 파일을 복사하거나 이름만 추가하는 작업이 아닙니다. AI가 기존 편집 도구로 준비본과 입력 연결을 만들고 시험합니다. 구조에 따라 추가 조정이나 지원되지 않는 항목이 있을 수 있으며, 자동 등록 단일 명령은 없습니다. [에이전트용 등록 절차](../plugins/hancom-desktop/skills/hwpx/references/complete-template-registration.md)를 따릅니다.

등록 후에는 “등록한 우리 학교 양식으로 다음 계획서를 작성해줘”라고 요청합니다. 여러 양식은 용도별로 구분하며 매번 새로 등록하지 않습니다. 개인 문서와 학생·교직원 정보는 공개 저장소에 올리지 않습니다.
